게임

(인터넷 필요 없음) (TLauncher는 안전한지 모르겠음 가능하면 쓰지 말고 https://github.com/PrismLauncher/PrismLauncher 아니면 minetest라는 것도 있긴한데 프리즘 런처(크랙은 안전한지 모름https://github.com/Diegiwg/PrismLauncher-Cracked/releases) 쓰세요)
포켓몬 골드, 에메랄드도 가져와서 넣어놨고, 인터넷에 군대 html게임 등이라고 치면 많이 나옵니다.

인터넷 우회
차단에 사용되는 프로그램은 주로 그린inet에 있다. 뭐로 감시 당하는지 확인해서 특성에 따라서 우회하자.(tor는 일반적으로 거의 못 막는다)
vpn은 프록시와 같고(atozproxy나 프록시 체인이라는 것도 있다) 노드/proton vpn을 추천하고 tor포터블(브라우저, 매우 안전함) 버전을 들고 가는 것도 추천합니다. 크롬 확장 프로그램은 막히는 경우가 많아서 추천 안함.
dns는 1.1.1.1이나 8.8.8.8로 알고 있는 경우가 더 많을 것이고, https 차단을 막기 위한 것으로 대부분의 사이트 차단은 다 우회할 수 있습니다.
일반적으로는 유니콘을 사용하고 추가적으로 dns변조 프로그램을 구해서 넣어놨습니다.
